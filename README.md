# UC67017 Arduino Exercises

Collection of Arduino C++ exercises for the UC67017 course. Each directory is an independent example with its own `main.cpp` file.

## Repository Structure

| Directory | Topic |
| --- | --- |
| `arduino-hello-world` | Serial output, button reading, and a basic Hello World loop |
| `arduino-digital-output` | Digital input controlling an LED output |
| `arduino-digital-output-exercise` | Button-controlled LED with serial messages |
| `arduino-button-blink` | Blinking an LED with timed delays |
| `arduino-button-direction-control` | Four directional buttons controlling four LEDs |
| `arduino-button-millis-counter` | Button timing with `millis()`; work in progress |
| `arduino-four-buttons-switch-case` | Four buttons and diagonal direction selection |
| `arduino-switch-case` | Two-button state selection using `switch`/`case` |
| `arduino-struct-basics` | Representing buttons with a C++ `struct` |
| `arduino-relay-control` | Momentary relay activation from a button |
| `arduino-relay-motor-valve-control` | Relay control for a motor or valve |
| `arduino-sensors-relay-control` | Button or sensor input controlling a relay |

Some exercises also include breadboard diagrams or short evidence videos.

## Requirements

- Arduino-compatible board
- Arduino IDE or PlatformIO
- USB cable and the required electronic components
- Serial Monitor configured to `9600` baud for sketches that print status messages
